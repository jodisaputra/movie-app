# Movie App (React)

Aplikasi web React sederhana untuk melihat daftar film dan detailnya menggunakan API OMDb.

## Struktur Project

```text
src/
├── components/
│   ├── MovieCard.jsx
│   ├── MovieDetail.jsx
│   └── SearchBar.jsx
├── services/
│   └── movieService.js
├── App.css
├── App.jsx
├── index.css
└── main.jsx
```

## Cara Menjalankan

```bash
npm install
npm run dev
```
