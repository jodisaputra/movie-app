# Movie App

Aplikasi Flutter untuk melihat daftar film dan detail film menggunakan OMDb API.

## Struktur Project

```text
lib/
├── models/
│   ├── movie.dart
│   └── movie_detail.dart
├── services/
│   └── movie_service.dart
├── screens/
│   ├── movie_list_screen.dart
│   └── movie_detail_screen.dart
└── main.dart
```

## Cara Menjalankan

```bash
flutter pub get
flutter run
```
